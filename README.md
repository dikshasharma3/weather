# 🌦 Weather CLI App (Node.js)

A Node.js command-line application that provides real-time weather updates using the OpenWeatherMap API.

## 🔧 Features
- Get current weather for any city from the terminal
- Real-time data fetched from OpenWeatherMap API
- User-friendly CLI interface
- Lightweight and fast
- Built with Node.js

## 📦 Technologies Used
- Node.js
- JavaScript
- OpenWeatherMap API
- Git & GitHub
